# WF1 业务规范

## 六个阶段

1. 情境定向与需要诊断
2. 自主确立目标
3. 自主提出问题与制定计划
4. 自主探究、追问与解决
5. 成果验证与迁移
6. 反思调节与新一轮学习

## 目标结构

Bloom：B1 了解/记忆、B2 理解、B3 应用、B4 分析、B5 评价、B6 创造/创新。

SOLO：S0 前结构、S1 单点结构、S2 多点结构、S3 关联结构、S4 拓展抽象结构。Bloom 与 SOLO 分别表达，不合并为总分。

## 认知冲突门控

仅当 session_status=active、goal_confirmed=true、learning_contract_confirmed=true、learning_started=true、learner_evidence_valid=true 且 event_type 允许检测时启动。

冲突类型分为知识层（事实、概念）、推理层（协作、推理、控制）和元认知层（元认知知识、体验、监控）。

CCI 小于 2.5 为冲突不足；2.5 至 3.5 为适宜区；大于 3.5 为认知过载；目标中心约 3.0。同一证据事件最多调节 3 轮。单次过载必须先调节再复评，不能直接发送教师预警。
