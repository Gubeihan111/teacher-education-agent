# WF3 业务规范

## 进入条件

存在经过确认的教学任务、`GOAL_BASELINE`、基本教学设计、可运行的模拟课堂配置，以及初始支架和证据要求。

## 子图

- SG3.1 实践任务接入与训练配置
- SG3.2 教学情境与虚拟班级构建
- SG3.3 模拟课堂交互执行
- SG3.4 教师成长状态感知与临界预警
- SG3.5 动态支架与控制权调节
- SG3.6 关键课堂事件与专业判断训练
- SG3.7 课堂回放与证据化实践复盘
- SG3.8 再教学与稳定性验证

SG3.3 是运行核心；SG3.4、SG3.5、SG3.6 在运行中循环调用。SG3.7 负责关键片段回放与即时复盘。SG3.8 仅处理同情境或近变式再教学，更高层次迁移归 WF4。

成长状态：UNDER_CHALLENGED、OPTIMAL、AT_RISK、OVERLOADED、UNCERTAIN。

即时支架：L0 无支架、L1 最小提示、L2 策略性追问、L3 结构化局部支架。

长期控制权：C1 AI 较强引导、C2 人机协同、C3 师范生主导、C4 AI 退隐。

专业判断链：J1 关键事件感知 → J2 专业解释与依据 → J3 行动适切性 → J4 后续结果观察。

稳定输出：`TeachingJudgmentEvidencePackage`、`ImmediateImprovementTarget`、`RetryResult`、`NextStageRecommendation`。
