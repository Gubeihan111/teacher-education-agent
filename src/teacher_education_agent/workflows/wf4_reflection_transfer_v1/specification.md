# WF4 业务规范

输入包含 WF3 输出的 `TeachingJudgmentEvidencePackage`。

## 子图

- SG4.1 成长证据汇聚与反思任务生成
- SG4.2 自主问题发现
- SG4.3 证据核验与问题归因
- SG4.4 改进策略生成与选择
- SG4.5 改进实践验证
- SG4.6 迁移任务生成与独立挑战
- SG4.7 自主性与迁移达成判定

反思支架：R0 自主反思、R1 证据提醒、R2 定向反思追问、R3 结构化反思脚本。

反思过程维度：描述、评价、论证、替代方案、自我关联。SOLO 只用于辅助结构分析，不作为正式反思能力总分。

迁移任务：T1 近变式、T2 结构迁移、T3 复杂新情境。该分级是项目内部约定。

稳定输出：`ReflectionTransferEvidencePackage`、`NextGrowthProposal`。

改进实践通过 `practice_execution_facade` 复用 WF3 能力，WF4 不建设模拟课堂。
