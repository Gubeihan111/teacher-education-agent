# WF2 业务规范

流程：学习需要分析 → 学习者分析 → 学习目标制定与判断 → 学习内容制定与判断 → 教学策略制定 → 教学方法设计 → 教学媒体设计 → 教学过程设计 → 教学评价设计 → 目标—活动—评价一致性检查 → 修订改进。

## 节点语义

- N1 学习需要分析
- N2 学习者分析
- N3 学习目标制定
- N4 学习目标判断
- N5 学习内容制定
- N6 教学内容判断
- N7 教学策略制定
- N7-1 教学方法确定
- N7-2 教学媒体选择
- N7-3 教学过程设计
- N7-3-1 导入设计
- N7-3-2 新课讲授设计
- N7-3-3 复习总结设计
- N7-3-4 练习作业设计
- N8 授课类型判断
- N9 学习或作业证据是否达到要求
- N10 教学评价
- N11 修订改进

原材料 N7-3 的“教学过程实施”在本工程统一解释并命名为 `teaching_process_design`。不得使用 `teaching_process_execution`。真实课堂实施归 WF3。

稳定输出 `TeachingDesignPackage` 当前仅为契约占位，字段待业务专家确认。
